# Data

## Dataset Description
This project uses a multilingual corpus consisting of documents written in:

- English
- Hindi
- Telugu
- Tamil
- Bengali

The corpus contains structured text files representing various topics, including geography, festivals, science, education, culture, and general knowledge.

## Folder Structure
- `corpus/english/` — English documents
- `corpus/hindi/` — Hindi documents
- `corpus/telugu/` — Telugu documents
- `corpus/tamil/` — Tamil documents
- `corpus/bengali/` — Bengali documents

## Purpose
The dataset is used to test multilingual search behavior, Unicode processing, term matching, and ranking efficiency. It provides a practical environment for evaluating indexing and query-processing algorithms.

## Data Characteristics
- multiple languages
- Unicode content
- varying document themes
- searchable keyword corpus
- support for exact and fuzzy matching
