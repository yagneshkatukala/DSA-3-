# Read Me

This repository contains the Unicode Pattern Search Engine project for multilingual information retrieval.

## Project Title
Unicode Pattern Search Engine for Indian Language Wikipedia

## Repository Purpose
The project demonstrates how classical data-structure and algorithmic techniques can be used to build a practical search engine for Indian language and English text.
